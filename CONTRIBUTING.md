# Contributing to G-Contract

## Working language
**English is the working language of this repository.** Please write issues, pull requests, and comments in English so that all parties (the platform and content creators) can collaborate effectively.

- Issue templates are provided in English; keep your answers in English.
- If you must reference non-English material, add a short English summary.

## How to contribute
This repository is a **read-only mirror** generated by the platform from `G_Shared`. Do not modify contract files (`shared/**`, `docs/contracts/**`, `LICENSE`, `README.md`, `SECURITY.md`, `.github/**`) directly — such pull requests are rejected by the mirror-guard CI.

Use Issues instead:
- **Bug / contract ambiguity** → `bug` template
- **New capability / contract change** → `capability-request` template
- **Platform ↔ content handoff / open question** → `content-handoff` template

Flow: Issue → platform evaluation → contract PR in `G_Shared` → release announcement (CHANGELOG) → consumers pin the version themselves.

## Security
Report vulnerabilities privately per [SECURITY.md](SECURITY.md).
